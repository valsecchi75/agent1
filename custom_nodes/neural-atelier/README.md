# Neural Atelier

> Fashion-focused AI nodes for sketch-to-photo, styling, and recoloring.

## Nodes (3)

| Node | Description |
|------|-------------|
| NA - Sketch to Photo | Converts 2D sketches to photorealistic renders via Gemini Flash + Nano Banana |
| NA - Styling Detail Change | Targeted styling modifications on garments |
| NA - Recolor | Recolors garments to target Pantone color or reference image |

## Installation

Install from AGENT 1 Node Manager or download from the registry.

## Requirements

- AGENT 1 v0.8.0+
- Nano Banana API key
- Gemini API key (for Sketch to Photo)
